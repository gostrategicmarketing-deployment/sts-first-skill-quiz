# STS first skill quiz (example for Josh)

A clickable example of the School of Traditional Skills evergreen quiz funnel: the ad, the six-question "Which skill should you start first?" quiz, the email step, four result pages (Pantry, Herb Cabinet, Backyard Animals, From-Scratch Kitchen), checkout, welcome and the result email.

Offer modeled: $7 first month, then $29 a month. Nothing on the page is live, charged or sent. The page is marked noindex.

Jump to any step with the bar at the top, or link straight to one: `#ad`, `#quiz`, `#email`, `#result-pantry`, `#result-herbal`, `#result-animals`, `#result-kitchen`, `#checkout`, `#welcome`, `#result-email`.
